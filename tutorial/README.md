# HyperSpot tutorial: Human Kidney Cancer (tumour core, PD47171)

End-to-end example: raw Visium + scRNA-seq → Spotiphy single-cell decomposition → HyperSpot
cell-type-specific spatial domains (**ct-domains**) and their spatially variable genes (**ct-SVGs**).

| notebook | kernel | what it does |
|---|---|---|
| `00 Data Preparation` | HyperSpot | patient subset, Ensembl gene IDs, H&E image → Spotiphy inputs |
| `01 Spotiphy Deconvolution` | Spotiphy | proportions, nucleus segmentation, decomposition to single cells |
| `02 HyperSpot Preprocessing` | HyperSpot | project metadata, per-cell-type data, hypergraph |
| `03 HyperSpot Pipeline` | HyperSpot | `hyperspot` CLI: train → embed → domains → ct-domains → SVGs/ct-SVGs → per-gene table |
| `04 Exploring Results` | HyperSpot | domain maps, RCC ct-SVG tables and spatial plots, run stability |

## Setup
- Environments: `HyperSpot` (`pip install -e hyperspot`, which provides the `hyperspot` command) and
  `Spotiphy` (see the Spotiphy repository).
- Data (Li et al., *Cancer Cell* 2022, kidney cancer Visium + scRNA-seq), placed in
  `../demo/data_repo/Human Kidney Cancer/`:
  `RCC_upload_final_raw_counts.h5ad` and `visium_merge_core_upload.h5ad`. Change `DATA_DIR` in each
  notebook if they are elsewhere.
- Run every notebook **from this folder**. Outputs go to `spotiphy_project_files/` and
  `hyperspot_project_files/` here; both are git-ignored.
- Compute: Spotiphy and HyperSpot training use a GPU. Training is 1000 epochs.
- GPU: multi-GPU is not yet supported. With one GPU nothing needs to be set; with several, set
  `CUDA_VISIBLE_DEVICES` to a single GPU number (e.g. `0`) before running HyperSpot.

The notebooks are generated by `scripts/notebooks/build_tutorial_nbs.py`. Edit that script, not the
notebooks, then re-run it.
