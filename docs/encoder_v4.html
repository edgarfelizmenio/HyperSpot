CTHGCAEv4 — the type-aware hyperedge encoder

A plain hypergraph convolution blends every cell in a spatial neighborhood into one averaged vector, so abundant cell types drown out the rest. This encoder resolves each hyperedge into K per-type channels — each normalized by that type's own count, so a rare type's niche signal survives — then recombines them through a learned K×K cross-type gate. A cell ends up encoding the composition of its neighborhood, decoupled from raw abundance.

Each hyperedge becomes K vectors, not one — E ∈ ℝ^(M×K×D). Dividing each channel by de_(e,k), that type's own count, means a type contributing 3 cells is not swamped by one contributing 300: abundance is factored out, per-type niche signal preserved.

The wrapper CTHGCAEv4 discards this hₑ and instead pools the node embeddings ("spot" = own cells, or "neighborhood"), so the hyperedge task backprops straight into zᵢ.

Where the encoder sits

node_feats → CTTypeAwareEncoder → zᵢ (N×D)
zᵢ → CTHGMirrorDecoder → reconstruction (N×F)
zᵢ → pool(spot | neighborhood) → hyperedge_emb → HyperedgeDecoderopt

The encoder is the first block of the CTHGCAEv4 autoencoder: a mirror decoder reconstructs the input, and an optional hyperedge-autoencoder branch pools and reconstructs the node embeddings for tissue-domain clustering.
